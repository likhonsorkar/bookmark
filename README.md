# Bookmark — bookmark.likhon.com.bd

React + Tailwind CSS + Vite দিয়ে বানানো একটা সাধারণ বুকমার্ক/টুলস হাব। হোমপেজে
গ্রুপ করে বুকমার্ক দেখানো হয় — এখন পর্যন্ত একটা গ্রুপ হলো NESCO বিল চেকার
(প্রিপেইড ব্যালেন্স/রিচার্জ হিস্টোরি ও পোস্টপেইড বিলের হিসাব), আর আরেকটা গ্রুপ
সাধারণ লিংকের উদাহরণ। নতুন বুকমার্ক/লিংক যোগ করতে `src/bookmarks.js` ফাইলে একটা
এন্ট্রি বাড়ালেই হবে — কোনো অন্য কোড বদলাতে হবে না।

## Cloudflare Pages-এ ডিপ্লয়

Cloudflare Dashboard → Workers & Pages → Create → Pages → Git repo কানেক্ট করে:

- **Build command:** `npm run build`
- **Build output directory:** `dist`
- পরে Custom domain হিসেবে `bookmark.likhon.com.bd` যোগ করুন।

**রুট (`/prepaid`, `/invoice` …) কাজ করার ব্যবস্থা:** অ্যাপে এখন আসল URL রাউটিং আছে
(`src/router.jsx`), তাই রিফ্রেশ, ব্যাক বাটন ও নতুন ট্যাবে সরাসরি লিংক — সবই কাজ করবে।
Cloudflare Pages-এ প্রজেক্টে `404.html` না থাকলে অজানা যেকোনো পাথে নিজে থেকেই `index.html`
দেয় (SPA মোড), তাই আলাদা `_redirects` লাগে না। **প্রজেক্টে কখনো `404.html` যোগ করবেন না**,
করলে এই ব্যবস্থা বন্ধ হয়ে যায়।

**CORS:** `publicapi.likhon.com.bd`-এ CORS হেডার নেই, তাই ব্রাউজার `/api/...`-এ কল করে
(`src/api.js`) আর সেটা প্রক্সি হয়:

- **লোকাল** — `vite.config.js`-এর dev proxy (`npm run dev`)
- **Cloudflare** — `functions/api/[[path]].js` (Pages Function)। শুধু `nesco_pre` ও `nesco_post`
  পাথ ফরওয়ার্ড করে; `public/_routes.json` এর কারণে ফাংশনটি শুধু `/api/*`-এ চলে।

(সবচেয়ে ভালো স্থায়ী সমাধান হলো `publicapi.likhon.com.bd` সার্ভারেই `Access-Control-Allow-Origin`
হেডার যোগ করা — তখন প্রক্সি ছাড়াই চলবে।)

## PWA / অফলাইন

- `public/manifest.webmanifest` + আইকন (আপনার "L" লোগো থেকে বানানো) — ফোনে/ডেস্কটপে "Install"
  বা "Add to Home screen" করা যায়; হোম আইকন চেপে ধরলে প্রিপেইড/পোস্টপেইড/ক্যাশ মেমোর শর্টকাট আসে।
- `npm run build` চালালে `vite.config.js`-এর ছোট প্লাগিন `dist/sw.js` বানায় (টেমপ্লেট:
  `sw-template.js`), যেখানে বিল্ডের সব ফাইলের তালিকা বসানো থাকে। প্রথমবার খুললেই পুরো অ্যাপ
  ক্যাশ হয়ে যায়, তারপর ইন্টারনেট ছাড়াও ক্যাশ মেমো, সেটিংস ও প্রিন্ট কাজ করে।
- নেসকোর লাইভ তথ্য (`/api/*`) ইচ্ছা করেই ক্যাশ হয় না — অফলাইনে সেখানে "সার্ভারে পৌঁছানো যায়নি"
  মেসেজ আসে, আর উপরে একটা "অফলাইন" ব্যানার দেখায়।
- নতুন ডিপ্লয়ের পর নতুন ভার্সন পেতে একবার পেইজ রিলোড (বা অ্যাপ বন্ধ করে খোলা) লাগতে পারে।
- সার্ভিস ওয়ার্কার শুধু প্রোডাকশন বিল্ডে চালু থাকে; `npm run dev`-এ বন্ধ।

## ক্যাশ মেমো / Invoice

হোমপেজের "বিক্রয় রসিদ" গ্রুপে একটা "ক্যাশ মেমো / Invoice" টুল আছে (`src/pages/Invoice.jsx`) —
ক্রেতার নাম/মোবাইল/ঠিকানা, পণ্যের তালিকা (পণ্য, পরিমাণ, দর, মোট দাম), ডিসকাউন্ট ও সর্বমোট
হিসাব করে একটা প্রিন্টযোগ্য রসিদ বানায় (`src/print/invoice.js`)। প্রিন্ট সেটিংসে ভাষা বাংলা
রাখলে শিরোনাম হবে "ক্যাশ মেমো", English রাখলে "Invoice" — একই সেটিং টোকেন রসিদ ও এই
ইনভয়েস দুটোতেই কাজ করে।

## টোকেন প্রিন্ট

প্রিপেইড পেইজে রিচার্জ হিস্টোরি টেবিলের প্রতিটা সারিতে টোকেনের ঠিক আগের কলামে একটা
"প্রিন্ট" বাটন আছে — সেটাতে ক্লিক করলে ওই রিচার্জের একটা প্রিন্টযোগ্য টোকেন-রসিদ নতুন
ট্যাবে খুলে সরাসরি প্রিন্ট ডায়ালগ চলে আসে (`src/print/receipt.js`)।

হেডারের গিয়ার আইকনে ক্লিক করে সেটিংস পেইজে যাওয়া যায়, যেখান থেকে ঠিক করা যায়:

- **ভাষা** — বাংলা নাকি ইংরেজিতে রসিদ প্রিন্ট হবে
- **পেইজ সাইজ** — A5, থার্মাল ৮০মিমি, বা থার্মাল ৫৮মিমি (তিনটাই ছোট দোকানে সবচেয়ে বেশি ব্যবহৃত থার্মাল প্রিন্টারের সাইজ) — টোকেন রসিদ ও ক্যাশ মেমো দুটোতেই প্রযোজ্য
- **দোকানের তথ্য** — বাংলা ও English দুই ভাষাতেই আলাদা করে দোকানের নাম (বড় হরফে), মোবাইল ও ঠিকানা রাখা যায়; ক্যাশ মেমোতে এটা সবসময় দেখাবে, প্রিপেইড টোকেন রসিদে দেখাতে চাইলে আলাদা টগল অন করতে হবে। প্রতি ভাষায় রসিদের একদম নিচে বিজ্ঞাপন টেক্সটও রাখা যায় (একাধিক লাইনসহ; ক্যাশ মেমোতে সবসময়, টোকেন রসিদে দোকানের তথ্য টগল অন থাকলে)

এই সেটিংস `localStorage`-এ সংরক্ষিত হয় (`src/settings.js`), অ্যাকাউন্ট বা সার্ভারে না —
তাই প্রতিটা ডিভাইস/ব্রাউজারে আলাদাভাবে সেট করতে হবে, একটাতে বদলালে অন্যটায় প্রভাব পড়বে না।

## ডিজাইন নোট

- হেডার এখন পুরো স্ক্রিন-প্রস্থ জুড়ে একটা স্টিকি বার, ভিতরের কনটেন্ট `max-w-6xl` পর্যন্ত চওড়া —
  বড় মনিটরে আর সরু-কলাম দেখাবে না।
- বড় স্ক্রিনে (`lg:` ব্রেকপয়েন্ট থেকে) মিটার/কাস্টমার প্যানেল ও বিল সামারি পাশাপাশি সাজানো থাকে,
  ছোট স্ক্রিনে একটার নিচে একটা।
- মোবাইলে (৬৪০পিক্সেলের নিচে) রিচার্জ হিস্টোরি ও বিলের তালিকা টেবিলের বদলে কার্ড-লিস্ট হিসেবে
  দেখানো হয়, বড় স্ক্রিনে টেবিল ফিরে আসে (`sm:hidden` / `hidden sm:block` দিয়ে টগল করা)।

## চালানোর নিয়ম

```bash
npm install
npm run dev       # লোকাল ডেভ সার্ভার (CORS প্রক্সিসহ)
npm run build     # প্রোডাকশন বিল্ড (dist/ ফোল্ডারে)
npm run preview   # বিল্ড করা ভার্সন প্রিভিউ (PWA দেখা যাবে; API প্রক্সি শুধু dev/Cloudflare-এ)
```

## ফোল্ডার গঠন

```
functions/api/[[path]].js   Cloudflare Pages Function — NESCO API প্রক্সি
sw-template.js               সার্ভিস ওয়ার্কারের টেমপ্লেট (বিল্ডে dist/sw.js হয়)
public/                      manifest, আইকন/লোগো, _routes.json, _headers
src/
  router.jsx            ছোট History-API রাউটার (usePath / Link / navigate) — লাইব্রেরি ছাড়া
  api.js               /api/... পাথে ফেচ করে (dev proxy / Cloudflare Function-এর মাধ্যমে NESCO API-তে যায়)
  bookmarks.js          হোমপেজের সব বুকমার্ক/টুলসের তালিকা — নতুন লিংক এখানে যোগ করুন
  settings.js            লোকাল প্রিন্ট সেটিংস (ভাষা/পেইজ সাইজ/বাংলা+English দোকানের তথ্য), localStorage-এ
  App.jsx               কোন পেইজ দেখাবে তার state ও লেআউট
  index.css             Tailwind directives + বেস স্টাইল
  print/
    shared.js             esc/nl2br/pageCss/print-window — সব প্রিন্ট টেমপ্লেটের কমন হেল্পার
    receipt.js            টোকেন রসিদের HTML বানিয়ে প্রিন্ট ডায়ালগ খোলে
    invoice.js             ক্যাশ মেমো/ইনভয়েসের HTML বানিয়ে প্রিন্ট ডায়ালগ খোলে
  components/
    Header.jsx          ব্র্যান্ড বার, "সব বুকমার্ক"-এ ফেরার বাটন ও সেটিংস আইকন
    CustomerForm.jsx     কনজ্যুমার নম্বর ইনপুট ফর্ম (NESCO টুলে ব্যবহৃত)
    InfoGrid.jsx         কী-ভ্যালু তথ্য দেখানোর জন্য
  pages/
    Home.jsx             বুকমার্ক গ্রিড
    Prepaid.jsx           NESCO প্রিপেইড ব্যালেন্স, রিচার্জ হিস্টোরি ও টোকেন প্রিন্ট
    Postpaid.jsx          NESCO পোস্টপেইড বিলের হিসাব
    Invoice.jsx            ক্যাশ মেমো/ইনভয়েস বানানোর ফর্ম
    Settings.jsx           প্রিন্ট সেটিংস পেইজ
```

নতুন কোনো টুল (NESCO-র মতো ফর্ম-ভিত্তিক পেইজ) যোগ করতে চাইলে `pages/`-এ একটা
কম্পোনেন্ট বানান, `App.jsx`-এ একটা `view` কেস যোগ করুন, আর `bookmarks.js`-এ
`type: 'internal'` দিয়ে একটা এন্ট্রি বাড়িয়ে দিন। শুধু বাইরের কোনো লিংক হলে
`type: 'external'` দিয়ে সরাসরি `bookmarks.js`-এ যোগ করলেই হবে, কোড বদলানোর
দরকার নেই।
